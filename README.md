# Проект веб-приложения интернет-магазина
## Описание:
**Данное приложение предполагает создание веб-приложения интернет-магазина.**
## Цель проекта:
Реализовать приложение, который на бэкенде будет выводить информацию о товарах интернет-магазина и обрабатывать запросы.
## Установка:
1. Клонируйте репозиторий:
```python
https://github.com/PetrMaev/online_shop.git
```
```python
git@github.com:PetrMaev/online_shop.git
```
2. Установите зависимости:
```python
poetry install
```
## Использование:
Для запуска программы введите в терминале следующую команду:
```python
python manage.py runserver
```
## На данном этапе в проекте реализованы:
1. Контроллеры для отображения домашней html-страницы и страницы с контактной информацией со стилизацией Bootstrap.
2. Настроена маршрутизация для этих контроллеров.
3. Реализована форма обратной связи на странице контактов.
